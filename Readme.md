# Лабораторная работа №3

**Тема:** JavaScript.

### Реализованный функционал:
* `isInteger(n)` — функция, которая проверяет, является ли число целым, используя побитовые операторы.
* `even()` — функция, которая возвращает массив четных чисел от 2 до 20 включительно.
* `sumTo(n)` — функция, считающая сумму чисел до заданного используя цикл.
* `recSumTo(n)` — функция, считающая сумму чисел до заданного используя рекурсию.
* `factorial(n)` — функция, считающая факториал заданного числа.
* `isBinary(n)` — функция, которая определяет, является ли число двойкой, возведенной в степень.
* `fibonacci(n)` — функция, которая находит N-е число Фибоначчи.
* `getOperationFn(initialValue, operatorFn)` — функция, которая принимает начальное значение и функцию операции и возвращает функцию, выполняющую эту операцию.
* `sequence(start, step)` — функция создания генератора арифметической последовательности.
* `deepEqual(firstObject, secondObject)` — функция, которая принимает два значения и возвращает true только в том случае, если они эквивалентны.
* Все 16 автотестов успешно пройдены.
