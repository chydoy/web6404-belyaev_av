# Лабораторная работа №2

**Тема:** Музей ретро-компьютеров «RetroTech 80s» (HTML и CSS).

### Реализованный функционал:s
* **Многостраничность:** 4 страницы с единым меню навигации (`index.html`, `exhibits.html`, `specs.html`, `visit.html`).
* **HTML:** Использование семантических тегов HTML5, блочных и строчных элементов, относительных ссылок, картинок, списков и форм.
* **Таблица:** Сравнительная таблица характеристик компьютеров с тремя видами выравнивания ячеек (по левому краю, по центру и по правому краю).
* **CSS:** Отдельный подключаемый файл `style.css`, ретровейв-палитра (неон 80-х).
